# NoteHub — Global State with Zustand

NoteHub notes app on Next.js where the note creation form moved to a separate page and its draft is stored in a global Zustand store, so the user never loses unfinished text.

## 🔗 Links

- **Live Demo:** [https://08-zustand-roan-pi.vercel.app](https://08-zustand-roan-pi.vercel.app)
- **Source code:** [github.com/vitalii1408/08-zustand](https://github.com/vitalii1408/08-zustand)

## 🛠 Tech Stack

- Next.js (App Router)
- React
- TypeScript
- Zustand (persist)
- TanStack Query
- Axios
- CSS Modules
- Vercel

## ✨ Features

- Separate page for creating a note
- Note draft saved in Zustand with persistence in localStorage
- Filter notes by tags, search with debounce, pagination
- Note preview in a modal via intercepting routes
- SEO metadata (Open Graph) for pages

## 🚀 Getting Started

```bash
git clone https://github.com/vitalii1408/08-zustand.git
cd 08-zustand
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
